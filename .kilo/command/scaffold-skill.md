---
description: Create a new skill under .kilo/skills/<name>/SKILL.md with valid frontmatter and a workflow body.
---

Create .kilo/skills/$1/SKILL.md.

- Frontmatter must include a valid, unique name ($1) and a description written in the third person that states when to use the skill and its triggers.
- Body must cover: when to use it, the workflow (numbered steps), the pitfalls to avoid, and how to verify the work.
- Follow the style of the existing skills in .kilo/skills/ and do not modify them.
- Confirm the created path when done.
