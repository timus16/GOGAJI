# Vedic Wallpaper Aesthetics - AI Generation Skill

## Purpose
Guide for generating premium Vedic astrology wallpapers using NVIDIA flux.1-dev that are visually stunning, traditionally authentic, and distinct per problem area/preset.

## Research-Based Aesthetic Principles

### Traditional Yantra Design (from Wikipedia research)
- **Bindu**: Central point representing the deity - must be prominent
- **Trikona**: Triangles - downward (Shakti/feminine), upward (Shiva/masculine)
- **Satkona**: Interlocking hexagrams (Shiva-Shakti union)
- **Lotus (Kamal)**: 8, 16, 24, 32, 100, 1000 petals - purity/transcendence
- **Circle (Gola)**: 3 concentric circles - manifestation
- **Outer Square (Bhupura)**: 4 cardinal directions with doorways (Chakora)
- **Colors**: White (sattva/purity), Red (rajas/activation), Black (tamas/inertia) - symbolic not decorative

### Nakshatra Symbolism (27 nakshatras with symbols, deities, planetary rulers)
Each nakshatra has:
- Symbol (horse head, yoni, knife, cart, deer, teardrop, bow, cow udder, serpent, throne, bed legs, hand, jewel, plant shoot, archway, lotus, amulet, roots, elephant tusk, ear, drum, empty circle, swords, twins, fish)
- Deity (Ashvins, Yama, Agni, Brahma, Soma, Rudra, Aditi, Brihaspati, Nagas, Pitrs, Bhaga, Aryaman, Savitr, Vishwakarma, Vayu, Indra, Mitra, Nirrti, Apah, Visvedevas, Vishnu, Vasus, Varuna, Ajaikapada, Ahirbudhnya, Pushan)
- Planetary ruler (Ketu, Venus, Sun, Moon, Mars, Rahu, Jupiter, Saturn, Mercury)
- Traditional syllable for pada

### Preset Aesthetic Archetypes (5 presets)
1. **Temple Gold** - Deep umber, beaten gold, grain texture, 4 rings, 24 petals, traditional temple aesthetic
2. **Indigo Midnight** - Night indigo, moonlit silver, rays texture, 3 rings, 16 petals, cosmic/night sky
3. **Minimal Line-Art** - Parchment, hairline weight, none texture, 2 rings, 12 petals, clean sacred geometry
4. **Dense Mandala** - Saturated, maximal ornament, dots texture, 6 rings, 32 petals, intricate tantric
5. **Royal Marigold** - Oxblood-marigold, foil frame, rays texture, 5 rings, 28 petals, regal/festival

### Problem Area Visual Themes (8 areas)
- **Career**: Solar/martial energy, upward triangles, gold/amber, Ketu/Sun symbols
- **Wealth**: Venus/Lakshmi energy, lotus, pink/green, Shukra symbols
- **Relationships**: Moon/Venus union, interlocking circles, silver/pink, Chandra/Shukra
- **Health**: Mars/fire energy, triangles, red/orange, Mangala symbols
- **Education**: Mercury/budhi, geometric precision, green/yellow, Budha symbols
- **Spiritual**: Jupiter/Guru, Sri Yantra structure, yellow/white, Guru symbols
- **Protection**: Saturn/Rahu/Ketu, defensive squares, dark blue/black, Shani/Rahu symbols
- **Family**: Moon/Jupiter, nurturing circles, white/gold, Chandra/Guru symbols

## Prompt Engineering Rules for flux.1-dev

### Structure
```
[Central Motif] + [Nakshatra Symbol] + [Deity Reference] + [Ruling Planet Colors] + [Problem Area Mood] + [Preset Style] + [Technical Specs]
```

### Technical Specs (always include)
- "No readable text, no watermarks, no signatures"
- "Intricate sacred geometry, traditional yantra construction"
- "High resolution, 832x1216, vertical wallpaper format"
- "Devanagari mantra as visual texture only, not readable"

### Quality Markers
- Bindu must be visually central
- Triangles must be geometrically precise
- Lotus petals evenly distributed
- Colors follow guna symbolism (white/red/black base)
- Outer square with 4 gateways
- Nakshatra symbol integrated as central motif
- Planetary color palette dominant

## Validation Checklist
- [ ] Central bindu visible
- [ ] Nakshatra symbol recognizable
- [ ] Planetary colors correct
- [ ] Problem area theme expressed
- [ ] Preset style applied
- [ ] No text artifacts
- [ ] Aspect ratio 832:1216
- [ ] Sacred geometry precise
